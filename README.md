One letter for your day: **B** — for *burnout*. The honest one-word report
of a day spent grinding through the night, entry after entry, until the
tank is empty. The program writes exactly that one letter to
/output/entry.txt — nothing else, no word, no gloss, no punctuation.

## Run it

```sh
python3 main.py
```
